What this preview does and does not show

  • Shown: the responsive breakpoint working — full-width container, fluid hero image, 20px mobile gutters, reduced headline size, and the full-width CTA.
  • Shown: the CSS button. Outlook sees the <v:roundrect> VML button instead, which is hidden from every non-Outlook client by conditional comments.
  • Not shown: the Outlook ghost table. The <!--[if mso]> 600px wrapper exists because Outlook honours neither max-width nor margin: auto.
  • Not shown: the hidden preheader text, which appears next to the subject line in inbox list views, not in the message body.
  • Not shown: Gmail's ~102KB clipping threshold, spam filtering, or deliverability. Run those checks separately — see docs/TESTING.md.
  • Image paths: the production file uses relative paths so this preview works offline. Swap them for absolute HTTPS URLs before sending — see docs/DEPLOYMENT.md.
  • Local server: if the frames above are empty, you opened this over file://. Some browsers block local iframes. Serve the project over HTTP instead — see the README.
